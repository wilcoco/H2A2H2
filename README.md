## H2A2H2 Web

Three-pane knowledge editor to turn AI conversations into shareable knowledge graphs.

### Quickstart

```bash
npm ci
cp .env.local.example .env.local # create and set DATABASE_URL, AUTH_SECRET, OPENAI_API_KEY
npm run dev
# http://localhost:3000
```

Deployment (Railway): push to main triggers build.
